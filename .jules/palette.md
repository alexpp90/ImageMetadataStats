## 2025-03-01 - Global Cursors in Tkinter
**Learning:** In Tkinter, setting the `cursor` property via `ttk.Style().configure` (e.g. `cursor='hand2'`) is silently ignored because it is a widget-level option, not a style option. Furthermore, setting a global cursor on container widgets (like `root.option_add('*TNotebook.cursor', 'hand2')`) introduces severe UX regressions because child widgets inherit the cursor if they don't explicitly define one, leading to the entire page incorrectly displaying a hand cursor.
**Action:** Only apply cursors to specific interactive leaf widgets (e.g., `*TButton.cursor`, `*TCheckbutton.cursor`) using the Tk option database (`root.option_add`).
