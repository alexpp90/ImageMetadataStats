## 2024-08-19 - Speeding up OpenCV Laplacian Edge Detection
**Learning:** In OpenCV, using `cv2.CV_64F` for `cv2.Laplacian` operations is significantly slower than using `cv2.CV_32F`. In our benchmarks on large images (like 1024x1024 arrays), using 32-bit floats provides nearly a 3x speedup with minimal impact on variance/sharpness logic. The `var()` calculation on 32-bit float laplacian returns `numpy.float32`, which can easily be cast back to `float()` to maintain strict serialization and downstream type consistency without losing speed.
**Action:** Replace `cv2.CV_64F` with `cv2.CV_32F` when running intermediate `cv2.Laplacian` computations that don't require the strictest 64-bit precision, but be sure to cast the resulting aggregates (like `.var()` or `.median()`) to standard `float()`.
